🔧 Configuración Local - Supabase

ℹ️ Información:
Esta página te ayuda a configurar las variables de entorno necesarias para ejecutar la aplicación en desarrollo local. Las variables se guardarán en localStorage del navegador.
Obtenerlo en: Supabase Dashboard → Settings → API → Project URL
Obtenerlo en: Supabase Dashboard → Settings → API → anon public

📊 Valores Actuales

📝 Pasos siguientes:

  1. Completa el formulario arriba con tus credenciales de Supabase
  2. Haz clic en "Guardar Configuración"
  3. Crea usuarios de prueba en Supabase Auth (ver SUPABASE_AUTH_SETUP.md)
  4. Vuelve a la aplicación principal e intenta hacer login
